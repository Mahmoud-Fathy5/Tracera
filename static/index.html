Advanced Forensic
Spectral Analysis

Tracera utilizes a sophisticated 2‑stage AI pipeline to ensure media integrity. First, we determine binary authenticity. If a deepfake is detected, our spectral engine identifies the specific generative model family.

shield

Stage 1: Real / Fake Detection

VGG-16 extracts Gram matrix eigenvalue features from multiple convolutional layers. XGBoost analyzes the new compact spectral fingerprint (Top-8 Eigenvalues, Spectral Slope, Energy Bands) to detect manipulation artifacts invisible to the human eye.

hub

Stage 2: Model Attribution

When a fake is detected, a second XGBoost classifier analyzes the same spectral features to distinguish between GAN-generated (StyleGAN, ProGAN) and Diffusion-generated (Stable Diffusion, DDPM) images.
